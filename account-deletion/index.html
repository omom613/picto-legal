계정 및 데이터 삭제

시행일: 2026년 7월 22일 · 버전 1.1

픽토 계정과 클라우드에 백업된 데이터를 삭제하는 방법을 안내합니다. 앱을 설치하지 않았거나 앱에 접근할 수 없어도 이 페이지의 방법으로 요청할 수 있습니다.

1. 앱에서 직접 삭제하기

앱을 사용할 수 있다면 설정 > 계정 및 백업 > 계정 삭제에서 직접 진행하는 것이 가장 빠릅니다. 요청 즉시 인증 계정과 클라우드 데이터가 삭제됩니다.

2. 이메일로 요청하기

앱을 사용할 수 없다면 가입에 사용한 이메일 주소로 goodpicto@gmail.com에 삭제를 요청해 주세요. 본인 확인 후 처리하며, 접수일로부터 영업일 기준 7일 이내에 완료하고 결과를 회신합니다.

3. 삭제되는 데이터

인증 계정, 클라우드에 동기화된 기록과 설정, 사진 메타데이터와 비공개 백업 사진이 삭제됩니다. 삭제 후에는 복구할 수 없습니다.

4. 기기에 남는 데이터

기기 안에만 저장된 기록은 클라우드와 별개입니다. 앱의 설정 > 내 데이터 > 전체 데이터 삭제에서 지우거나, 앱을 삭제하면 함께 사라집니다.

5. 보관이 필요한 경우

법령상 보관 의무가 있는 정보가 있다면 해당 법령이 정한 기간 동안만 분리 보관한 뒤 파기합니다. 그 밖의 정보는 즉시 파기합니다.
