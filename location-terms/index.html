위치기반서비스 이용약관

시행일: 2026년 7월 22일 · 버전 1.1

이 약관은 픽토가 사진의 위치 정보와 사용자가 허용한 현재 위치를 이용해 지도와 장소 기반 기록 기능을 제공하는 조건을 정합니다.

1. 목적과 적용 범위

이 약관은 픽토의 위치 기반 기능을 이용하는 사용자와 픽토 운영팀 사이의 권리, 의무 및 이용 조건에 적용됩니다. 운영체제의 사진 또는 위치 권한 동의는 이 약관 동의와 별도로 요청됩니다.

2. 제공하는 위치 기반 기능

픽토는 사진에 포함된 촬영 좌표를 지도에 표시하고, 가까운 사진을 장소별로 묶고, 지역명을 만들어 기록과 통계에서 다시 볼 수 있게 합니다. 사용자가 내 위치 기능을 실행하면 대략적 현재 위치를 지도 시작점으로 사용합니다.

3. 이용하는 위치 정보와 방법

사진 위치는 사용자가 접근을 허용한 기기 갤러리의 사진 메타데이터에서 확인합니다. 현재 위치는 사용자가 지도 또는 위치 연결 기능을 실행하고 운영체제 권한을 허용한 경우에만 전경에서 확인합니다. 픽토는 정확한 기기 위치 권한과 백그라운드 위치를 요청하지 않으며 이동 경로를 상시 추적하지 않습니다.

4. 이용 목적과 보관

현재 위치는 지도 중심을 정하는 데 일시적으로 사용하며 별도 기록으로 저장하지 않습니다. 사진 좌표와 이를 바탕으로 만든 지역명은 사용자가 해당 사진을 기록에 직접 담은 경우 기록의 일부로 기기에 보관됩니다. 계정 동기화와 사진 백업을 사용하면 기록에 포함된 좌표와 지역명이 다른 기록 정보와 함께 비공개 클라우드에 보관될 수 있습니다.

5. 외부 서비스와 제공 제한

지도 표시에는 NAVER Cloud 지도 SDK를 사용하고, 사용자가 선택한 계정 동기화와 백업에는 Supabase를 사용합니다. 픽토는 위치 기반 기능 제공과 사용자가 선택한 백업에 필요한 범위를 넘어 개인 위치 정보를 제3자에게 판매하거나 제공하지 않습니다.

6. 사용자의 선택과 권리

사용자는 사진 또는 위치 권한을 허용하지 않고도 위치 기능을 제외한 기록 기능을 이용할 수 있습니다. 기기 설정에서 언제든 권한을 철회할 수 있고, 기록의 사진과 장소 정보를 수정하거나 기록을 삭제할 수 있습니다. 계정 및 백업을 사용하는 경우 계정 삭제를 통해 클라우드의 기록과 사진 위치 정보도 삭제할 수 있습니다.

7. 이용 요금과 서비스 변경

현재 위치 기반 기능에는 별도 이용 요금이 없습니다. 통신 요금은 사용자의 가입 조건에 따릅니다. 운영체제, 지도 사업자 또는 서비스 정책 변경으로 기능이 바뀌거나 중단될 수 있으며 중요한 변경은 앱 안에서 안내합니다.

8. 아동의 위치 정보

법정대리인의 동의가 필요한 연령의 사용자가 개인 위치 정보를 이용하는 경우 관계 법령에 따른 동의 절차가 필요합니다. 정식 계정 서비스의 대상 연령과 법정대리인 절차는 배포 정책에서 별도로 확정합니다.

9. 문의와 분쟁 해결

위치 정보의 이용, 권한 철회와 삭제는 앱의 설정, 내 데이터 및 계정 및 백업에서 관리할 수 있습니다. 위치 정보와 관련한 분쟁은 상호 협의를 우선하고, 해결되지 않는 경우 관계 법령에 따른 분쟁 조정 절차를 이용할 수 있습니다. 문의는 픽토(Picto) 운영자 ms, goodpicto@gmail.com으로 보낼 수 있습니다.
