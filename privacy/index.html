3. 이용 목적

수집한 정보는 오늘 기록, 타임라인, 캘린더, 지도, 검색, 통계, 기억 꺼내기와 보고서를 제공하기 위해 사용합니다. 계정에 로그인한 사용자가 선택한 경우에는 계정 인증, 여러 기기 동기화, 비공개 사진 백업과 복원을 위해 사용합니다. 서비스 보안과 오류 복구를 위한 최소한의 동기화 상태도 처리합니다.

4. 사진과 위치 정보

사진 및 위치 권한은 관련 기능을 사용할 때 별도로 요청합니다. 픽토는 사용자가 선택한 사진의 원본 메타데이터에 위치가 있을 때 해당 좌표를 지도와 지역명 기능에 사용합니다. 지도 중심을 현재 위치로 옮길 때는 운영체제가 제공하는 대략적 위치를 일시적으로 사용하며, 이를 별도 기록으로 저장하지 않습니다. 정확한 위치나 백그라운드 위치는 요청하지 않습니다. 권한을 거부하거나 철회해도 해당 권한이 필요하지 않은 기록 기능은 계속 사용할 수 있습니다.

5. 건강 데이터

사용자가 건강 데이터 연결을 선택하면 픽토는 Android Health Connect에서 걸음 수, 이동 거리, 운동 시간과 수면 세션을 읽습니다. 걸음, 거리, 운동 원본과 수면 단계는 픽토 서버에 저장하지 않습니다. 오늘 기록에 자동 입력된 수면 시간은 사용자가 저장할 때 일반 기록의 일부로 기기에 보관되며, 계정 백업을 사용하면 다른 기록과 함께 동기화될 수 있습니다.

6. 저장, 보유와 삭제

로그인하지 않은 기록은 기본적으로 사용 중인 기기의 앱 저장소에 저장됩니다. 계정에 로그인하면 기록과 설정이 동기화되고, 기록에 직접 담은 사진이 비공개 클라우드 저장소에 백업될 수 있습니다. 기기 데이터는 사용자가 개별 기록 또는 전체 데이터를 삭제하거나 앱 저장소를 지울 때까지 보관합니다. 클라우드 데이터는 계정을 유지하는 동안 보관하며, 계정 삭제를 실행하면 인증 계정, 클라우드 기록, 사진 메타데이터와 비공개 백업 사진을 삭제합니다.

앱에서 계정을 삭제하려면 설정의 계정 및 백업 화면을 이용할 수 있습니다. 앱에 접근할 수 없는 경우에는 계정 삭제 안내를 확인하거나 문의처로 삭제를 요청할 수 있습니다.

7. 위탁과 외부 서비스

픽토는 계정 인증, 데이터베이스 동기화와 사진 백업을 위해 Supabase, Inc.의 서비스를 사용합니다. 현재 주 저장 리전은 대한민국 서울(ap-northeast-2)이며, 계정 식별자, 이메일, 동기화 기록과 사용자가 백업한 사진이 해당 기능 제공을 위해 처리될 수 있습니다. 지도 화면에는 NAVER Cloud의 지도 SDK를 사용합니다. 픽토는 개인정보를 판매하지 않으며, 별도 동의나 법률상 의무가 없는 한 독립된 제3자에게 제공하지 않습니다.

8. 안전성 확보 조치

클라우드 통신에는 암호화된 연결을 사용하고, 인증 토큰은 기기의 보안 저장소에 보관합니다. 클라우드 기록에는 사용자별 접근 제어를 적용하며 사진 저장소는 비공개로 운영합니다. 기기 전용 사진 URI와 갤러리 자산 식별자는 클라우드 기록에서 제외합니다.

9. 이용자의 권리

사용자는 앱에서 기록을 열람, 수정, 삭제하고 권한을 철회할 수 있습니다. 기기 전체 데이터와 클라우드 계정도 삭제할 수 있습니다. 계정 삭제 후 클라우드 데이터는 복구할 수 없으며, 기기에 남은 데이터는 앱의 내 데이터 메뉴에서 별도로 삭제해야 합니다.
