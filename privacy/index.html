개인정보처리방침

시행일: 2026년 9월 25일 · 버전 1.3

픽토는 로컬 우선 방식으로 동작하며, 사용자가 선택한 기록 기능과 계정 백업에 필요한 정보만 처리합니다.

1. 처리 주체와 적용 범위

픽토(Picto) 운영자 ms는 픽토 앱에서 처리되는 개인정보의 처리자입니다. 이 방침은 기기 내 기록, 선택적 계정, 클라우드 동기화와 사진 백업에 적용됩니다.

2. 처리하는 정보

기기 기록: 기분, 활동 칩, 직접 입력하거나 건강 연결에서 가져온 수면 시간, 메모, 중요한 날, 즐겨찾기와 앱 설정. 사진 기록: 사용자가 선택한 사진, 촬영 시각, 파일 형식과 크기, 사진에 포함된 경우 위도·경도 및 이를 바탕으로 만든 지역명. 선택적 건강 연결: 걸음 수, 이동 거리, 운동 시간과 수면 세션. Google 계정 기능: 이메일 주소, Google이 제공한 프로필 정보, Supabase 사용자 식별자와 인증 세션 정보. 동기화 정보: 생성·수정 시각, 버전과 동기화 상태. 진단 정보: 기기 종류, 운영체제와 앱 버전, 오류 정보 및 온보딩·첫 기록 완료 여부. 픽토는 Google 비밀번호, 광고 식별자, 연락처, 마이크 음성 또는 동영상을 수집하지 않습니다.

3. 처리 목적

정보는 오늘 기록, 타임라인, 캘린더, 지도, 검색, 통계, 기억 꺼내기와 보고서를 제공하고, 사용자가 선택한 경우 계정 인증, 여러 기기 동기화, 비공개 사진 백업과 복원을 제공하기 위해 처리합니다. 서비스 보안과 오류 복구를 위한 최소한의 동기화 상태도 처리합니다.

4. 처리 방법과 선택권

로그인하지 않은 기록은 기본적으로 사용 중인 기기의 앱 저장소에만 저장됩니다. 계정에 로그인하면 기록과 설정이 자동 동기화되고 백업되지 않은 기록 사진이 비공개 클라우드 저장소에 업로드될 수 있습니다. 계정을 만들지 않아도 핵심 기록 기능을 이용할 수 있습니다.

5. 사진과 위치 정보

픽토는 사용자가 선택한 사진의 원본 메타데이터에 위치가 있을 때 해당 좌표를 읽어 기기 안의 지도와 지역명 기능에 사용합니다. 계정 동기화를 선택하면 클라우드에는 좌표를 소수점 셋째 자리로 줄여 약 100m 단위의 대략적 위치만 전송합니다. 지도 중심을 현재 위치로 옮길 때는 운영체제가 제공하는 대략적 위치를 일시적으로 사용하며 이를 별도 기록으로 저장하지 않습니다. 정확한 기기 위치 권한은 요청하지 않습니다. 사진 또는 위치 권한을 거부하면 관련 기능만 제한됩니다.

5-1. 건강 데이터

사용자가 건강 데이터 연결을 선택하면 픽토는 Android Health Connect에서 걸음 수, 이동 거리, 운동 시간과 수면 세션을 읽습니다. 걸음, 거리, 운동 원본과 수면 단계는 픽토 서버에 저장하지 않습니다. 오늘 기록에 자동 입력된 수면 시간은 사용자가 저장할 때 일반 기록의 일부로 기기에 보관되며, 계정 백업을 사용하면 다른 기록과 함께 동기화될 수 있습니다. 연결하지 않거나 접근 권한을 철회하면 자동 입력만 중단되며 다른 기록 기능에는 영향이 없습니다.

6. 보유 기간과 삭제

기기 데이터는 사용자가 개별 기록 또는 전체 데이터를 삭제하거나 앱 저장소를 지울 때까지 보관됩니다. 클라우드 데이터는 계정을 유지하는 동안 보관됩니다. 계정 삭제를 실행하면 인증 계정, 클라우드 기록, 사진 메타데이터와 비공개 백업 사진을 삭제합니다. 동기화 과정에서 삭제 상태는 다른 기기 반영을 위해 일시적으로 처리될 수 있습니다.

7. 처리 위탁과 클라우드

계정 인증, 데이터베이스 동기화와 사진 백업을 위해 Supabase, Inc.의 서비스를 사용합니다. 현재 픽토 프로젝트의 주 저장 리전은 대한민국 서울(ap-northeast-2)이며, 위탁 정보는 계정 식별자, 이메일, 동기화 기록과 사용자가 백업한 사진입니다. 위탁 기간은 계정 삭제 또는 위탁 계약 종료 시까지입니다. 지도 화면 제공에는 NAVER Cloud의 지도 SDK가 사용됩니다. 앱 오류와 최초 이용 흐름의 중단 지점을 파악하기 위해 Functional Software, Inc.(Sentry)에 오류 보고 및 온보딩·약관 동의·첫 기록 완료 여부를 보냅니다. 여기에는 기기 종류, 운영체제 버전, 앱 버전과 종료 직전의 화면 이동 기록이 포함될 수 있으며, 파일 경로·이메일·정밀 위치·기록 내용·사진·메모는 전송 전에 제외합니다. 플러스 구독을 이용하는 경우 구매 상태 확인을 위해 RevenueCat, Inc.에 구매 식별자와 구독 상태가 전달됩니다.

8. 제3자 제공과 판매

픽토는 사용자의 개인정보를 판매하지 않으며, 사용자의 별도 동의나 법률상 의무가 없는 한 독립된 제3자에게 제공하지 않습니다. 클라우드, 지도, 오류 보고와 결제 사업자는 픽토를 대신해 기능을 제공하는 처리 수탁자로 사용됩니다. 픽토는 광고 식별자를 수집하지 않고 광고 목적의 추적을 하지 않습니다.

9. 안전성 확보 조치

클라우드 통신에는 암호화된 연결을 사용하고, 인증 토큰과 작성 중인 일기 초안 및 최근 장소 캐시는 기기의 보안 저장소를 사용합니다. 클라우드 기록에는 사용자별 접근 제어를 적용하고 사진 저장소는 비공개로 운영합니다. 기기 전용 사진 URI와 갤러리 자산 식별자는 클라우드 기록에서 제외하며, Android의 운영체제 자동 백업과 기기 간 전송에서 앱 내부 데이터가 복사되지 않도록 제외합니다.

10. 사용자의 권리와 행사 방법

사용자는 앱에서 기록을 열람·수정·삭제하고, 권한을 철회하며, 기기 전체 데이터 또는 클라우드 계정을 삭제할 수 있습니다. 계정 삭제 후 클라우드 데이터는 복구할 수 없습니다. 기기에 남은 데이터는 내 데이터에서 별도로 삭제해야 합니다.

11. 아동의 개인정보

픽토는 만 14세 미만 아동을 대상으로 하지 않으며 해당 연령의 이용을 허용하지 않습니다. 최초 이용 시 약관 동의와 함께 만 14세 이상인지 확인하며, 확인 완료 여부만 기기에 저장합니다. 이전 버전에서 이용을 시작해 확인 기록이 없는 경우에는 생년월일 입력으로 확인하며, 입력한 생년월일은 연령 확인에만 사용하고 저장하거나 전송하지 않습니다. 만 14세 미만의 이용 사실을 알게 되면 이용을 제한하고 관련 개인정보를 관계 법령에 따라 처리합니다.

12. 보호책임자와 문의

개인정보 관련 문의처는 픽토(Picto) 운영자 ms, goodpicto@gmail.com입니다. 현재 사용자는 설정 > 내 데이터 및 계정 및 백업에서 열람과 삭제 기능을 직접 이용할 수 있습니다.

13. 방침 변경

이 방침이 변경되면 시행일과 주요 변경 내용을 앱 안에서 알립니다. 처리 목적, 항목 또는 제3자 제공 등 중요한 내용이 바뀌어 별도 동의가 필요한 경우에는 해당 기능을 사용하기 전에 다시 안내하고 동의를 받습니다.
